Generated by the Backstage **kargo-wiring** golden-path template. This dir (`services/${{ values.name }}/kargo/`)
is a `.Files.Get` packaging-shim Helm chart carrying the raw Kargo CRs (Project · Warehouse · dev/prod
Stages · credentials · dev-verify AnalysisTemplate · ProjectConfig). The `apps/platform/delivery/kargo-projects.yaml`
ApplicationSet **auto-discovers** `services/*/kargo/` → an ArgoCD app `kargo-${{ values.name }}` appears
with **no extra app wiring**.

**Warehouse model:** `${{ values.warehouseModel }}` · **dev-smoke variant:** `${{ values.smokeVariant }}` ·
**auto-promote dev:** `${{ values.autoPromoteDev }}`

Division of labour: **CI builds & proves the artifact · Kargo promotes it · ArgoCD deploys it.** Never
hand-edit `image.tag` — Kargo owns the bump.

## Prerequisites (must already be true)
1. The service has a **dev deployment** in namespace `${{ values.name }}` (the Kargo project lives in the
   same ns). The `minicloud-platform` AppProject allow-lists all non-system namespaces, so `${{ values.name }}`
   is already permitted — no AppProject edit needed.
2. The image is **env-agnostic** (runtime config) and prod pins an **immutable ghcr SHA tag** — both
   `values-dev.yaml` and `values-prod.yaml` write `minicloud-app-deployment.image.tag` as **block-style
   YAML** (never flow `{ tag: … }` — Kargo's yaml-update cannot mutate a flow map).
3. The first ghcr image exists (`ghcr.io/andrelair-platform/${{ values.imageBasename }}:<sha>`).

### MANDATORY image-model check — NewestBuild must be able to RANK builds
NewestBuild silently stalls ("newest already exists") if the image's build timestamp is NOT monotonic
(a fixed base-layer date, or a reproducible build with a pinned `config.created`). Verify the discovered
tags have **distinct** `createdAt`:
```bash
kubectl --context minicloud get warehouse ${{ values.name }} -n ${{ values.name }} -o json \
  | jq '.status.discoveredArtifacts.images[].references[] | {tag, createdAt}'
```
If the dates are **identical across different tags** → NewestBuild is broken → **switch this Warehouse to
the git model** (re-run the template with `warehouseModel=git`, or copy `services/ktayl-policy-service/kargo/`).
Do NOT hand-edit the dev tag to route around it.
{%- else %}

### git-model note
Freight keys on the commit (`commitFrom(...).ID[0:7]` == the CI 7-char short-SHA tag) — timestamp-independent,
so it's immune to the NewestBuild trap. The `excludePaths` guard must stay a **superset** of the source
repo's CI `paths-ignore` (docs-only / `[skip ci]` commits must never create un-built Freight →
ImagePullBackOff). A public source repo needs no git credential.
{%- endif %}

## Promotion flow
- **dev:** {% if values.autoPromoteDev %}auto-promoted by Kargo (ProjectConfig) → a dev-overlay PR (label `automerge`) that the dev auto-merge workflow squash-merges.{% else %}manual (Kargo UI) — no auto-promotion policy was generated.{% endif %}
- **verification:** the `${{ values.name }}-dev-verify` AnalysisRun (variant ${{ values.smokeVariant }}) must pass → the Freight becomes `verifiedIn:[dev]`.
- **prod:** only dev-verified Freight is promotable; Kargo opens a **CODEOWNERS-gated** prod PR. **Squash-merge it** (Kargo commits are unsigned; `main` requires verified signatures). Prod still goes through the **QA gate** first (`qa-gate.md`).
